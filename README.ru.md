# BABYLON — The Ishtar Gate, 575 BCE

[English version](README.md)

Интерактивная кинематографическая реконструкция Дороги процессий и Ворот Иштар в Вавилоне эпохи Навуходоносора II.
Работает в браузере в реальном времени: Three.js r186, TypeScript, Vite, WebGL2.

```bash
git clone https://github.com/Borq1000/babylon-ishtar-gate.git
cd babylon-ishtar-gate
npm install
npm run dev        # → http://localhost:5173
```

Нужны Node.js 18+ (проверено на 22) и браузер с WebGL 2 (Chrome или Edge — лучше всего).

Продакшн-сборка: `npm run build`, затем `npm run preview`.

## Управление

| | |
|---|---|
| **Enter Babylon** | кинематографический тур (~65 с), затем свободная прогулка |
| **Cinematic Tour / Explore** | переключение режимов (кнопки на титуле и в нижней панели) |
| `W A S D` / стрелки | ходьба (в режиме Explore) |
| мышь | осмотр (клик по сцене захватывает курсор) |
| `Shift` | ускорить шаг |
| `Esc` | освободить курсор |
| `H` | скрыть / показать интерфейс |
| `P` | счётчик FPS, draw calls, треугольников |

Звук включается только после первого клика пользователя; переключатель Sound — на титуле и в панели.

## Что реализовано

**Архитектура (герой-ассет).**
- Двойные Ворота Иштар: передние ворота, световой колодец, главные ворота глубиной 33 м с аркой ≈11,8 м.
- Кедровые створки с бронзовыми полосами и бобышками.
- Шесть чередующихся рядов быков (*rīmu*) и драконов *mušḫuššu*: все идут к проходу, а внутри прохода — на юг, в город.
- Вертикальные рамки, ленты розеток, ступенчатые глазурованные зубцы.
- Дорога процессий длиной 180 м: стены с неглубокими башнями, **60 львов на каждой стороне** с шагом 3 м, бирюзовый регистр и полосы розеток в порядке берлинской реконструкции.
- Мощение: 5 известняковых плит по 105 см в центре, красная брекчия по 66 см с белыми прожилками, битумные швы, обожжённый кирпич до стен.
- Северные ворота, ров шириной 80 м с дамбой, внешняя и внутренняя городские стены с башнями.
- Город: Южный и Северный дворцы с дворами, храм Нинмах (белёный, ступенчатые борозды), Этеменанки по ярусам стелы с синим храмом наверху, Эсагила, Евфрат, около 1000 детальных домов и тысячи дальних (инстансинг).

**Рельефы.**
- Скульптурные панели генерируются из контуров по фотографиям музейных оригиналов (CC0/PD):
  - лев (Met 31.13.2) обведён сплайнами;
  - силуэты тура и дракона (Стамбул) векторизованы с фото сегментацией цвета;
  - зеркальные панели сдвинуты на полкирпича, чтобы швы совпадали со стеной.
- Слои контуров → точное евклидово поле расстояний (EDT) → профиль «лепки» → пряди гривы, чешуя, завитки шерсти → сквозные швы формованных кирпичей.
- Реальное смещение геометрии в трёх LOD, карты нормалей / AO / шероховатости и текстурный ray-march самозатенения рельефа от солнца.
- Генерация идёт в Web Workers.
- Края панелей зубчатые по швам кладки, поэтому панели бесшовно сидят в стене.

**Материалы.**
- Процедурные PBR-текстуры запекаются на GPU при загрузке: кобальтовая глазурь (обжиговые вариации, истончение глазури на рёбрах, наклоны кирпичей ради бликов), обожжённый кирпич, известняк, брекчия, ленты.
- Фото-текстуры CC0 Poly Haven: песок, штукатурка, дерево, ткань, кора пальмы.
- Пыль у оснований стен, макро-вариации, «макро-окклюзия» каньона коридора и тоннелей ворот.

**Свет и атмосфера.**
- Небо Preetham с перистыми облаками, звёздами и луной; IBL из того же неба (PMREM).
- Нативные каскадные тени `SunLight` (r186).
- Пост-эффект воздушной перспективы: высотная дымка цвета неба и объёмные лучи по ray-march теневой карты.
- N8AO, bloom, тонмаппинг Khronos PBR Neutral, сдержанный грейдинг.
- Пыль, видимая только в лучах солнца; дым очагов, курильниц и жаровен; стаи стрижей.

**Жизнь города.**
- Процессия Акиту: стража с копьями и щитами, штандарты с лопатой-*marru* Мардука, барабанщики и лиристы, бритоголовые жрецы с курильницами, носильщики с паланкином статуи бога, знать с посохами, народ.
- Прохожие (у носильщиков корзины, у женщин кувшины на голове), зрители (некоторые машут процессии), стража у ворот, часовые на стенах, горожане и рынок на площади.

**Люди.**
- Около 260 человек. Тела, лица, глаза, волосы и бороды — CC0-ассеты MakeHuman, собранные в Blender (MPFB 2).
- Нововавилонская одежда генерируется по фигуре:
  - длинные и короткие туники со складками, шерстяной фактурой, бордюром у подола;
  - шаль с бахромой через плечо, покрывала у женщин;
  - повязки, тюрбаны, шапки, шлемы.
- Движение — настоящий мокап CMU: ходьба, медленный шаг, марш, стояние, разговор, взмах рукой. Клипы перенесены на скелет MakeHuman и зациклены.
- Для предметов руки поставлены аналитической IK, предметы жёстко привязаны к кистям или голове.
- Отрисовка:
  - скининг на GPU из общей текстуры матриц костей, инстансинг;
  - 8 архетипов × 4 LOD (≈26 тыс. → 0,8 тыс. треугольников);
  - тени — от лёгких LOD-прокси.

**Режимы.** Титульный «наплыв», кинематографический тур по сплайнам (Catmull–Rom + монотонная развёртка времени), исследование от первого лица со столкновениями.

**Время суток.** Morning, Midday, Golden Hour, Night: плавные переходы солнца/луны, неба, экспозиции и дымки, ночью — масляные факелы и жаровни.

**Звук.** Процедурный Web Audio без аудиофайлов:
- ветер, гул города, позиционные группы людей;
- барабаны, кимвалы и лира процессии;
- шаги, стрижи и горлицы, ночные сверчки, треск огня, вода во рву.

**Производительность.**
- Профили Low / High / Ultra и адаптивное разрешение.
- LOD и куллинг для рельефов, пальм и людей; тайловая нарезка города.
- Люди: несколько десятков draw call на всю толпу, цвета людей в статичной текстуре, в кадр загружаются только матрицы и курсоры анимации.

## Измерения (этот компьютер: NVIDIA RTX 2050 Laptop, Chrome / ANGLE D3D11)

- Загрузка до титула: около 3–6 с, включая GPU-запекание, генерацию рельефов в воркерах и компиляцию шейдеров.
- High, 1920×1080, стартовый кадр: GPU ≈ 13–17 мс на кадр (~60–75 FPS). Адаптивное разрешение держит частоту на тяжёлых ракурсах.
- High, 1280×720: ≈ 6–7 мс на кадр.
- Толпа из ~260 человек добавляет ≈ 3,5–4,5 мс при 1600×900 (High).
- Модели людей: ≈ 8 МБ (GLB со сжатием Draco) + атлас текстур 1 МБ.
- Звёздные 60 FPS на Ultra требуют видеокарту уровня RTX 3060+.

## Историческая основа и художественные допущения

Источники: R. Koldewey, *The Excavations at Babylon* (1914); O. Pedersén, *Babylon: The Great City* (2021, open access) и *Iraq* 2024; реконструкции Пергамского музея; Met Open Access.

Где данных нет или они спорны, приняты правдоподобные решения:
- **Высота стен коридора** неизвестна (в Берлине 12,5 м); здесь 11 м, чтобы ворота доминировали.
- **Направление львов** спорно. Сделано по берлинской реконструкции и Педерсену: львы идут на север, навстречу входящим.
- **Солнце в пресете Golden Hour** стоит севернее реального летнего азимута (322° вместо ≈295°), чтобы свет доставал до дна стенного коридора и фасада ворот.
- **Этеменанки** поставлен немного ближе к воротам (~650 м вместо ~800 м), чтобы читаться с высоты.
- Глазурованную «надпись Навуходоносора» из Берлина **не воспроизвожу**: это современная компиляция, её исходное место неизвестно.
- **Одежда, оружие стражи, вид процессии** — правдоподобная реконструкция: прямых нововавилонских изображений почти нет.

## Структура

```
src/
  core/          App (цикл кадра, свет, атмосфера), качество, адаптивное разрешение
  rendering/     PostFX, эффект атмосферы/объёмного света, грейдинг, теневая карта объёма
  materials/     GPU-запекание текстур, ленты, библиотека материалов, шейдерные патчи
  shaders/       общий GLSL: шум, кирпичная кладка, небо
  architecture/  ворота и стены (Monuments), город (City), набор деталей, рельефы (reliefs/)
  characters/    загрузка людей и запекание анимаций, шейдер GPU-скининга, симуляция толпы и процессии
  environment/   небо, время суток, пальмы, вода, пыль, дым, птицы, рынок, ночные огни
  camera/        тур, контроллер от первого лица, столкновения, режимы
  audio/         процедурный звуковой ландшафт (Web Audio)
  ui/            интерфейс и стили
  dev/           страница трассировки рельефов: /dev/relief.html?a=lion&mode=trace (или mode=maps)
public/          CC0-текстуры и модели Poly Haven (см. ASSET_CREDITS.md)
reference/       референсы для трассировки (не входят в сборку), источники — reference/SOURCES.md
tools/people/    скрипты Blender, которыми собраны люди (не входят в сборку)
```

## Известные ограничения

- **Люди**:
  - одежда без симуляции ткани: юбка деформируется скелетом, шаль и бордюры нарисованы шейдером;
  - вблизи видны стыки рукава и туники на плечах;
  - волосы и бороды — карточки MakeHuman с альфа-тестом;
  - мимики нет.
- **Объёмные лучи** считаются по статической теневой карте крупной архитектуры: люди и пальмы в них не участвуют.
- **Отражения** в воде и глазури берутся из карты неба: SSR и планарных отражений нет.
- **Глобального освещения** нет: отражённый свет имитируют IBL и макро-окклюзия.
